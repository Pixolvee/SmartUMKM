# SmartUMKM

Aplikasi manajemen operasional bisnis dan kasir (POS) modern untuk UMKM Indonesia.

## Fitur Utama

- **Kasir / Point of Sale (POS)**: Pencatatan pesanan cepat, draf pesanan, kalkulasi otomatis, dan cetak struk transaksi.
- **Produk & Inventaris**: Pengelolaan katalog produk, pemantauan stok menipis, dan peringatan minimum stok.
- **Produksi & Resep**: Pencatatan hasil produksi barang dan estimasi kebutuhan bahan baku.
- **Keuangan & Pembukuan**: Pencatatan pendapatan, pengeluaran operasional, dan pemantauan arus kas.
- **Pelanggan & CRM**: Database pelanggan dan pelacakan status loyalitas.
- **Pegawai & Shift**: Manajemen shift kerja operasional.
- **Laporan & Analitik**: Laporan penjualan, margin produk per unit, ekspor data CSV, dan cetak laporan PDF.

## Pengembangan Lokal

Pastikan Anda telah menginstal Node.js (>= 20) atau Bun.

```sh
npm install
npm run dev
```

Aplikasi akan berjalan di `http://localhost:3000` (atau port yang ditentukan Vite).

## Pengujian & Pengecekan

```sh
npm test
npm run lint
```

## Teknologi

- **Framework**: TanStack Start (Full-stack React)
- **Bahasa**: TypeScript
- **Styling**: Tailwind CSS v4
- **Database / Auth**: Supabase
- **Icons**: Lucide React
- **Komponen UI**: Radix UI
